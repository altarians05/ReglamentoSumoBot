Cap. 6: Sistema de Competencia y Sorteos
Formato del Torneo y Sorteos

El formato oficial de la competencia será determinado por el Comité Organizador basándose estrictamente en la cantidad de robots homologados y el tiempo disponible. Existen dos modalidades principales (Art. 6.1):

A. Formato Mixto

Fase de Grupos seguida de Eliminación Directa. Recomendado para garantizar un mínimo de combates por equipo.

B. Eliminación Directa Pura

Aplicable en caso de limitaciones severas de tiempo o un volumen excesivo de participantes.

Sorteos (Art. 6.2): La conformación de grupos y emparejamientos se realizará mediante sorteo público o software aleatorio para garantizar total transparencia.
Sistema de Puntuación (Fase de Grupos)

Si se utiliza la modalidad de grupos, la clasificación se determinará mediante el siguiente sistema (Art. 6.3):

3 PTS Combate Ganado
0 PTS Combate Perdido
3 PTS + 2 YUKO Walkover (Incomparecencia)
Criterios de Desempate

Si dos o más equipos terminan con los mismos puntos, se aplica este orden estricto (Art. 6.4 y 6.5):

1. Enfrentamiento Directo
Clasifica el equipo que haya ganado el combate disputado directamente entre los equipos empatados.
2. Menor Peso
De persistir el empate, clasifica el equipo cuyo robot haya registrado el menor peso durante la fase oficial de homologación.
3. Mejores Terceros (Si aplica)
Se elaborará una tabla virtual comparando únicamente a los terceros lugares de cada grupo, aplicando estos mismos criterios para completar las llaves finales.
Fase de Eliminación y Podio Final

El camino hacia la victoria sigue esta estructura en la fase final (Art. 6.6 y 6.7):

Formación de Llaves Se cruzan los clasificados según su posición (Ej. 1° Grupo A vs 2° Grupo B). Para avanzar, se deben obtener 2 Puntos Yuko. El perdedor queda eliminado.
3º
Tercer Puesto Los dos equipos perdedores de las Semifinales disputarán un combate adicional para determinar el 3er y 4to lugar del podio.
Gran Final (Campeón) Los ganadores de Semifinales se enfrentan. El ganador será declarado Campeón del torneo y el perdedor obtendrá el título de Subcampeón.
